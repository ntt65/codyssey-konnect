## 1. 실제 RAG 연결 확인 — 먼저 진행

- [ ] 답변 제공자에 맞게 OpenAI 또는 Naito 설정 입력

- [ ] 자료 적재 명령 실행 및 성공 확인

- [ ] 임시 검증 자료를 실제 앱 자료와 분리 — 검증용 컬렉션 사용 가능

완료 기준: 실제 DB와 LLM으로 적재 → 검색 → 답변 → 출처 확인을 한 번 끝낸다.
